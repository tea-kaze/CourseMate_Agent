# CourseMate 接口文档

> 版本：v0.1.0 ｜ 更新日期：2026-08-16 ｜ 对应后端：`coursemate/app/main.py`

## 1. 概述

- **Base URL**：`http://127.0.0.1:8000`（前端可用环境变量 `COURSEMATE_API` 覆盖）
- **协议与编码**：HTTP / JSON（UTF-8）；文件上传为 `multipart/form-data`；流式接口（`/chat/stream`）为 SSE（`text/event-stream`）
- **鉴权**：无（单用户本地模式），CORS 已放开
- **在线文档**：Swagger UI：`http://127.0.0.1:8000/docs`

## 2. 通用约定

- 成功返回 `2xx`；请求体校验失败返回 `422`；资源不存在返回 `404`；会话课程范围冲突返回 `409`；文档资源删除失败返回 `503`；其他业务错误通常返回 `400`，未处理的服务端异常返回 `500`。
- 错误响应统一为 JSON：`{"detail": "错误描述"}`（`/chat/stream` 例外：流中途失败以 `error` 事件返回，HTTP 状态仍为 200）
- 时间字段为 ISO 8601 字符串，例如 `2026-08-15T10:00:00`。

## 3. 接口总览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查 |
| GET | `/courses` | 课程列表 |
| POST | `/courses` | 创建课程（表单参数） |
| GET | `/documents` | 文档列表 |
| POST | `/documents` | 上传文档入库（multipart） |
| DELETE | `/documents/{document_id}` | 删除文档（含向量与原文） |
| POST | `/chat` | Agent 对话（支持多轮历史与会话） |
| POST | `/chat/stream` | Agent 流式对话（SSE 逐 token） |
| GET | `/chat/sessions` | 会话列表（按最后活动时间倒序） |
| POST | `/chat/sessions` | 新建会话 |
| GET | `/chat/sessions/{session_id}/messages` | 读取某会话全部消息 |
| DELETE | `/chat/sessions/{session_id}` | 删除会话（级联删除消息） |
| POST | `/questions/generate` | 自动出题 |
| POST | `/questions/{question_id}/grade` | 批改作答 |
| GET | `/stats/mistakes` | 错题统计（可按课程/题型/知识点过滤） |

## 4. 接口详情

### 4.1 GET /health

健康检查。

响应：

```json
{"status": "ok"}
```

### 4.2 GET /courses

课程列表，包含文档数量。只统计并返回至少含一份 `ready` 文档的课程；`pending / ingest_failed / deleting / delete_failed` 文档不会让课程出现在公开列表中。

响应：

```json
[
  {"id": 1, "name": "操作系统", "description": "", "document_count": 3}
]
```

### 4.3 POST /courses

创建课程。已存在同名课程时返回该课程（幂等）。

请求（`application/x-www-form-urlencoded`）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 课程名称 |
| `description` | string | 否 | 课程描述，默认空 |

响应：同 `GET /courses` 单条结构。

### 4.4 GET /documents

文档列表（按创建时间倒序），只返回 `ready` 文档。

响应：

```json
[
  {
    "id": 1,
    "course_id": 1,
    "course_name": "操作系统",
    "filename": "第一章.md",
    "doc_type": "md",
    "chunk_count": 12,
    "created_at": "2026-08-15T10:00:00"
  }
]
```

### 4.5 POST /documents

上传文档并入库：保存原文 → 创建 `pending` 元数据 → 解析切分 → 写入向量 → 更新为 `ready`。失败时尝试清理部分向量与原文，并将元数据记录为 `ingest_failed`；失败记录不会出现在课程和文档列表中。

请求（`multipart/form-data`）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 支持 `.pdf / .md / .markdown / .txt / .docx` |
| `course_name` | string | 否 | 课程名称，默认「默认课程」；不存在时自动创建 |

响应：

```json
{
  "document_id": 3,
  "filename": "第一章.docx",
  "chunk_count": 18,
  "course_id": 1,
  "course_name": "操作系统"
}
```

错误：

- `400`：不支持的文件类型；旧版 `.doc`（提示「请先另存为 .docx 后上传」）；解析不到文本（如扫描件 PDF 或空文档）。

### 4.6 DELETE /documents/{document_id}

删除文档：先把元数据标记为 `deleting`，再清理 Milvus 向量和上传原文，最后删除数据库记录。资源删除失败时保留记录和仍存在的资源，状态改为 `delete_failed`；再次请求同一 ID 会幂等重试。

响应：

```json
{"deleted": 3}
```

错误：

- `404`：文档不存在。
- `409`：文档当前状态不允许删除。
- `503`：向量或原文删除失败；记录已保留，可稍后重试。

### 4.7 POST /chat

Agent 对话。`session_id` 为空时自动新建会话，`course_id` 决定新会话的固定课程范围；两者都为空时创建全库会话。指定已有 `session_id` 后，以会话中保存的 `course_id` 为唯一范围，请求中的 `history` 不再使用，`course_id` 只能省略或与会话范围一致。

请求体：

```json
{
  "message": "什么是进程调度？",
  "course_id": 1,
  "history": [],
  "session_id": 5
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `message` | string | 是 | 用户消息，非空 |
| `course_id` | int | 否 | 新会话的固定课程范围；为空表示全库。已有会话不能通过该字段切换课程 |
| `history` | array | 否 | 兼容旧调用方；指定 `session_id` 时忽略 |
| `session_id` | int | 否 | 会话 ID；为空自动创建 |

响应：

```json
{
  "answer": "进程调度是操作系统对 CPU 时间进行分配的策略……",
  "session_id": 5,
  "session_title": "什么是进程调度？"
}
```

错误：`404`（会话或新会话指定的课程不存在）；`409`（已有会话与请求课程范围不一致，需新建会话）；`500`（Agent 调用失败，不落库）。

### 4.7.1 POST /chat/stream（流式对话）

与 `POST /chat` 语义一致，但响应为 SSE（`text/event-stream`），逐 token 返回回答。

请求体：同 `POST /chat`。

响应事件（每个 `data:` 一行 JSON）：

| type | 载荷 | 说明 |
| --- | --- | --- |
| `meta` | `session_id` | 首条，携带会话 ID |
| `token` | `content` | 回答 token |
| `error` | `message` | 流中途失败（此时不落库） |
| `done` | - | 正常结束 |

curl 示例：

```bash
curl -N -X POST http://127.0.0.1:8000/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"message": "什么是进程调度？", "course_id": 1}'
```

错误：建立流之前可能返回 `404`（会话或课程不存在）或 `409`（会话课程范围冲突）；流开始后的失败以 `error` 事件返回（HTTP 状态仍为 200）。

### 4.8 GET /chat/sessions

会话列表，按最后活动时间倒序。

响应：

```json
[
  {
    "id": 5,
    "title": "什么是进程调度？",
    "course_id": 1,
    "message_count": 2,
    "created_at": "2026-08-15T09:00:00",
    "updated_at": "2026-08-15T10:00:00"
  }
]
```

### 4.9 POST /chat/sessions

新建会话。`course_id` 为空时创建全库会话，否则绑定指定课程；课程范围创建后不可修改，切换课程需新建会话。

请求体：

```json
{"course_id": 1}
```

响应：同 `GET /chat/sessions` 单条结构（`message_count` 为 0）。

错误：`404`（指定课程不存在）。

### 4.10 GET /chat/sessions/{session_id}/messages

读取某会话全部消息（按时间升序）。

响应：

```json
[
  {"id": 1, "role": "user", "content": "什么是进程调度？", "created_at": "2026-08-15T09:00:00"}
]
```

`role` 取值：`user` / `assistant`。

错误：`404`（会话不存在）。

### 4.11 DELETE /chat/sessions/{session_id}

删除会话，级联删除该会话全部消息。

响应：

```json
{"deleted": 5}
```

错误：`404`（会话不存在）。

### 4.12 POST /questions/generate

自动出题：课程内检索 → 结构化 LLM 生成 → 持久化 → 映射为公开题目。该接口使用固定编排的 RAG 工作流，不经过 Agent 自主选路；参考答案和解析只保存在服务端，生成响应不返回这两个字段。

请求体：

```json
{
  "course_id": 1,
  "topic": "进程调度",
  "count": 3,
  "qtype": "mixed"
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `course_id` | int | 是 | 课程 ID |
| `topic` | string | 否 | 知识点；为空按课程整体出题 |
| `count` | int | 否 | 题目数量，1-20，默认 5 |
| `qtype` | string | 否 | `single` / `multiple` / `short` / `mixed`，默认 `mixed` |

响应：

```json
[
  {
    "id": 12,
    "course_id": 1,
    "qtype": "single",
    "topic": "进程调度",
    "stem": "时间片轮转属于哪种调度方式？",
    "options": ["A. 抢占式", "B. 非抢占式"]
  }
]
```

错误：`404`（课程不存在）；`500`（出题失败，如 LLM API 异常）。

### 4.13 POST /questions/{question_id}/grade

批改作答：题目 ID 只从路径读取。服务端读取题目、参考答案与课程范围，检索课程资料后执行结构化批改并记录作答；只有批改成功后才返回正确答案和解析。

请求体：

```json
{"user_answer": "A. 抢占式"}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `user_answer` | string | 是 | 作答内容，非空；多选题提交选项字母，如 `A、C` |

响应：

```json
{
  "attempt_id": 9,
  "is_correct": true,
  "score": 100,
  "feedback": "回答正确，时间片轮转属于抢占式调度。",
  "knowledge_point": "进程调度",
  "correct_answer": "A. 抢占式",
  "explanation": "时间片轮转按时间片切换进程，属于抢占式调度。"
}
```

错误：`404`（题目不存在）；`422`（`user_answer` 为空或请求体包含 `question_id` 等额外字段）；`500`（批改调用失败）。

### 4.14 GET /stats/mistakes

错题统计。聚合统计（累计作答、正确率、分布）为全量数据；`qtype` / `topic` 只过滤近期错题明细，且在 50 条上限之前生效。

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `course_id` | int | 否 | 课程过滤；为空统计全部课程 |
| `qtype` | string | 否 | 题型过滤：`single` / `multiple` / `short` |
| `topic` | string | 否 | 知识点精确过滤；空知识点按「未分类」 |

响应：

```json
{
  "total_attempts": 10,
  "correct_count": 6,
  "accuracy": 0.6,
  "by_type": {
    "single": {"total": 6, "correct": 4},
    "multiple": {"total": 4, "correct": 2}
  },
  "by_topic": {
    "进程调度": {"total": 10, "correct": 6}
  },
  "wrong_attempts": [
    {
      "attempt_id": 9,
      "question_id": 12,
      "stem": "时间片轮转属于哪种调度方式？",
      "qtype": "single",
      "topic": "进程调度",
      "options": ["A. 抢占式", "B. 非抢占式"],
      "user_answer": "B. 非抢占式",
      "correct_answer": "A. 抢占式",
      "feedback": "答案错误，请复习调度算法。",
      "score": 0,
      "created_at": "2026-08-15T10:00:00"
    }
  ]
}
```

## 5. 枚举与数据字典

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `qtype` | `single` / `multiple` / `short` / `mixed` | 题型；`mixed` 仅用于出题请求 |
| `role` | `user` / `assistant` | 会话消息角色 |
| `doc_type` | `pdf` / `md` / `markdown` / `txt` / `docx` | 文档类型，取文件扩展名 |
| `document.status` | `pending` / `ready` / `ingest_failed` / `deleting` / `delete_failed` | 内部文档生命周期；公开列表只返回 `ready` |
| `score` | 0-100（浮点） | 批改得分 |
| `accuracy` | 0.0-1.0（浮点） | 正确率 |

## 6. 调用示例

### curl

```bash
# 上传文档
curl -X POST http://127.0.0.1:8000/documents \
  -F "file=@第一章.docx" -F "course_name=操作系统"

# 发起问答
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "什么是进程调度？", "course_id": 1}'

# 错题统计（按题型过滤）
curl "http://127.0.0.1:8000/stats/mistakes?course_id=1&qtype=single"
```

### Python（httpx）

```python
import httpx

client = httpx.Client(base_url="http://127.0.0.1:8000", timeout=120)

resp = client.post(
    "/chat",
    json={"message": "什么是进程调度？", "course_id": 1},
)
print(resp.json())
```
