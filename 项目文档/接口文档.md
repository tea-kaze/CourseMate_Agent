# CourseMate 接口文档

> 版本：v0.1.0 ｜ 更新日期：2026-08-15 ｜ 对应后端：`coursemate/app/main.py`

## 1. 概述

- **Base URL**：`http://127.0.0.1:8000`（前端可用环境变量 `COURSEMATE_API` 覆盖）
- **协议与编码**：HTTP / JSON（UTF-8）；文件上传为 `multipart/form-data`
- **鉴权**：无（单用户本地模式），CORS 已放开
- **在线文档**：Swagger UI：`http://127.0.0.1:8000/docs`

## 2. 通用约定

- 成功返回 `2xx`；资源不存在返回 `404`；参数或业务错误返回 `400`；服务端异常返回 `500`。
- 错误响应统一为 JSON：`{"detail": "错误描述"}`
- 时间字段为 ISO 8601 字符串，例如 `2026-08-15T10:00:00`。

## 3. 接口总览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查 |
| GET | `/courses` | 课程列表 |
| POST | `/courses` | 创建课程（表单参数） |
| GET | `/documents` | 文档列表 |
| POST | `/documents` | 上传文档入库（multipart） |
| DELETE | `/documents/{document_id}` | 删除文档（含向量与原文） |
| POST | `/chat` | Agent 对话（支持多轮历史与会话） |
| GET | `/chat/sessions` | 会话列表（按最后活动时间倒序） |
| POST | `/chat/sessions` | 新建会话 |
| GET | `/chat/sessions/{session_id}/messages` | 读取某会话全部消息 |
| DELETE | `/chat/sessions/{session_id}` | 删除会话（级联删除消息） |
| POST | `/questions/generate` | 自动出题 |
| POST | `/questions/{question_id}/grade` | 批改作答 |
| GET | `/stats/mistakes` | 错题统计（可按课程/题型/知识点过滤） |

## 4. 接口详情

### 4.1 GET /health

健康检查。

响应：

```json
{"status": "ok"}
```

### 4.2 GET /courses

课程列表，包含文档数量。

响应：

```json
[
  {"id": 1, "name": "操作系统", "description": "", "document_count": 3}
]
```

### 4.3 POST /courses

创建课程。已存在同名课程时返回该课程（幂等）。

请求（`application/x-www-form-urlencoded`）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 课程名称 |
| `description` | string | 否 | 课程描述，默认空 |

响应：同 `GET /courses` 单条结构。

### 4.4 GET /documents

文档列表（按创建时间倒序）。

响应：

```json
[
  {
    "id": 1,
    "course_id": 1,
    "course_name": "操作系统",
    "filename": "第一章.md",
    "doc_type": "md",
    "chunk_count": 12,
    "created_at": "2026-08-15T10:00:00"
  }
]
```

### 4.5 POST /documents

上传文档并入库：校验扩展名 → 保存原文 → 解析切分 → 写入元数据与向量。

请求（`multipart/form-data`）：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 支持 `.pdf / .md / .markdown / .txt / .docx` |
| `course_name` | string | 否 | 课程名称，默认「默认课程」；不存在时自动创建 |

响应：

```json
{
  "document_id": 3,
  "filename": "第一章.docx",
  "chunk_count": 18,
  "course_id": 1,
  "course_name": "操作系统"
}
```

错误：

- `400`：不支持的文件类型；旧版 `.doc`（提示「请先另存为 .docx 后上传」）；解析不到文本（如扫描件 PDF 或空文档）。

### 4.6 DELETE /documents/{document_id}

删除文档：同时清理 Milvus 向量、上传原文与数据库记录。

响应：

```json
{"deleted": 3}
```

错误：`404`（文档不存在）。

### 4.7 POST /chat

Agent 对话。`session_id` 为空时自动新建会话；指定后历史一律从数据库读取（请求中的 `history` 不再使用）。

请求体：

```json
{
  "message": "什么是进程调度？",
  "course_id": 1,
  "history": [],
  "session_id": 5
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `message` | string | 是 | 用户消息，非空 |
| `course_id` | int | 否 | 课程范围；为空表示全部课程 |
| `history` | array | 否 | 兼容旧调用方；指定 `session_id` 时忽略 |
| `session_id` | int | 否 | 会话 ID；为空自动创建 |

响应：

```json
{
  "answer": "进程调度是操作系统对 CPU 时间进行分配的策略……",
  "session_id": 5,
  "session_title": "什么是进程调度？"
}
```

错误：`404`（会话不存在）；`500`（Agent 调用失败，不落库）。

### 4.8 GET /chat/sessions

会话列表，按最后活动时间倒序。

响应：

```json
[
  {
    "id": 5,
    "title": "什么是进程调度？",
    "course_id": 1,
    "message_count": 2,
    "created_at": "2026-08-15T09:00:00",
    "updated_at": "2026-08-15T10:00:00"
  }
]
```

### 4.9 POST /chat/sessions

新建会话。

请求体：

```json
{"course_id": 1}
```

响应：同 `GET /chat/sessions` 单条结构（`message_count` 为 0）。

### 4.10 GET /chat/sessions/{session_id}/messages

读取某会话全部消息（按时间升序）。

响应：

```json
[
  {"id": 1, "role": "user", "content": "什么是进程调度？", "created_at": "2026-08-15T09:00:00"}
]
```

`role` 取值：`user` / `assistant`。

错误：`404`（会话不存在）。

### 4.11 DELETE /chat/sessions/{session_id}

删除会话，级联删除该会话全部消息。

响应：

```json
{"deleted": 5}
```

错误：`404`（会话不存在）。

### 4.12 POST /questions/generate

自动出题：检索课程资料 → 结构化生成 → 持久化 → 返回带 ID 的题目列表。

请求体：

```json
{
  "course_id": 1,
  "topic": "进程调度",
  "count": 3,
  "qtype": "mixed"
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `course_id` | int | 是 | 课程 ID |
| `topic` | string | 否 | 知识点；为空按课程整体出题 |
| `count` | int | 否 | 题目数量，1-20，默认 5 |
| `qtype` | string | 否 | `single` / `multiple` / `short` / `mixed`，默认 `mixed` |

响应：

```json
[
  {
    "id": 12,
    "course_id": 1,
    "qtype": "single",
    "topic": "进程调度",
    "stem": "时间片轮转属于哪种调度方式？",
    "options": ["A. 抢占式", "B. 非抢占式"],
    "answer": "A. 抢占式",
    "explanation": "时间片轮转按时间片切换进程，属于抢占式调度。"
  }
]
```

错误：`404`（课程不存在）；`500`（出题失败，如 LLM API 异常）。

### 4.13 POST /questions/{question_id}/grade

批改作答：依据题目、参考答案、作答与课程资料上下文做结构化批改，并记录作答。

请求体：

```json
{"question_id": 12, "user_answer": "A. 抢占式"}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `question_id` | int | 是 | 题目 ID |
| `user_answer` | string | 是 | 作答内容，非空；多选题提交选项字母，如 `A、C` |

响应：

```json
{
  "attempt_id": 9,
  "is_correct": true,
  "score": 100,
  "feedback": "回答正确，时间片轮转属于抢占式调度。",
  "knowledge_point": "进程调度",
  "correct_answer": "A. 抢占式"
}
```

错误：`404`（题目不存在）；`500`（批改调用失败）。

### 4.14 GET /stats/mistakes

错题统计。聚合统计（累计作答、正确率、分布）为全量数据；`qtype` / `topic` 只过滤近期错题明细，且在 50 条上限之前生效。

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `course_id` | int | 否 | 课程过滤；为空统计全部课程 |
| `qtype` | string | 否 | 题型过滤：`single` / `multiple` / `short` |
| `topic` | string | 否 | 知识点精确过滤；空知识点按「未分类」 |

响应：

```json
{
  "total_attempts": 10,
  "correct_count": 6,
  "accuracy": 0.6,
  "by_type": {
    "single": {"total": 6, "correct": 4},
    "multiple": {"total": 4, "correct": 2}
  },
  "by_topic": {
    "进程调度": {"total": 10, "correct": 6}
  },
  "wrong_attempts": [
    {
      "attempt_id": 9,
      "question_id": 12,
      "stem": "时间片轮转属于哪种调度方式？",
      "qtype": "single",
      "topic": "进程调度",
      "options": ["A. 抢占式", "B. 非抢占式"],
      "user_answer": "B. 非抢占式",
      "correct_answer": "A. 抢占式",
      "feedback": "答案错误，请复习调度算法。",
      "score": 0,
      "created_at": "2026-08-15T10:00:00"
    }
  ]
}
```

## 5. 枚举与数据字典

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `qtype` | `single` / `multiple` / `short` / `mixed` | 题型；`mixed` 仅用于出题请求 |
| `role` | `user` / `assistant` | 会话消息角色 |
| `doc_type` | `pdf` / `md` / `markdown` / `txt` / `docx` | 文档类型，取文件扩展名 |
| `score` | 0-100（浮点） | 批改得分 |
| `accuracy` | 0.0-1.0（浮点） | 正确率 |

## 6. 调用示例

### curl

```bash
# 上传文档
curl -X POST http://127.0.0.1:8000/documents \
  -F "file=@第一章.docx" -F "course_name=操作系统"

# 发起问答
curl -X POST http://127.0.0.1:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "什么是进程调度？", "course_id": 1}'

# 错题统计（按题型过滤）
curl "http://127.0.0.1:8000/stats/mistakes?course_id=1&qtype=single"
```

### Python（httpx）

```python
import httpx

client = httpx.Client(base_url="http://127.0.0.1:8000", timeout=120)

resp = client.post(
    "/chat",
    json={"message": "什么是进程调度？", "course_id": 1},
)
print(resp.json())
```
