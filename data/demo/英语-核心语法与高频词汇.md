# 英语：核心语法与高频词汇（演示资料）

## 1. 常用时态

- 一般现在时：表示习惯、客观事实与规律，主语为第三人称单数时谓语动词加 -s；
- 一般过去时：表示过去发生的动作或状态，动词用过去式；
- 一般将来时：will + 动词原形，或 be going to + 动词原形；
- 现在进行时：am/is/are + doing，表示正在发生或按计划即将发生；
- 现在完成时：have/has + 过去分词，强调过去的动作对现在的影响或一直持续到现在，常见标志词有 already、yet、just、since、for、ever、never；
- 过去完成时：had + 过去分词，表示“过去的过去”。

现在完成时与一般过去时的区别：一般过去时只陈述过去，与现在无关；现在完成时一定与现在有联系。

示例：I have lived here for five years.（现在完成，表示持续至今）I lived in Beijing in 2020.（一般过去，与现在无关）

## 2. 被动语态

被动语态结构：be + 过去分词，动作的承受者作主语。常见时态的被动形式：一般现在 is/are done，一般过去 was/were done，现在完成 has/have been done，含情态动词用 must be done 等。

转换要点：把主动句的宾语提前作主语，原主语用 by 引出（可省略）；双宾语动词（give、send、show）转换后可以保留间接宾语；感官动词 look、smell、taste 以及 need、want、require 后用主动形式表被动含义，例如 The book is worth reading. / The room needs cleaning.

## 3. 定语从句

定语从句修饰名词，被修饰的名词称为先行词。关系代词：who（人，主格/宾格）、whom（人，宾格）、whose（表所属）、which（物）、that（人、物均可）。关系副词：where（地点）、when（时间）、why（原因）。

限制性定语从句与先行词关系紧密，不使用逗号；非限制性定语从句起补充说明作用，用逗号隔开，且不能用 that，指人用 who、指物用 which。

只能用 that 的常见情况：先行词被序数词或最高级修饰；先行词是 all、anything、nothing 等不定代词；先行词既有人又有物。介词提前时只能用 which 或 whom，例如 This is the house in which I lived.

## 4. 虚拟语气与情态动词

if 条件句的三种类型：

- 与现在事实相反：If + 过去式（be 用 were），主句 would/could/might + 动词原形；
- 与过去事实相反：If + had done，主句 would/could + have done；
- 与将来事实相反：If + should/were to + 动词原形，主句 would + 动词原形。

wish 后面的从句同样使用“时态退一格”的虚拟语气；It's (high) time that 后接过去式或 should + 动词原形。

情态动词表推测：must 表示很有把握的肯定推测；may/might 表示可能性；can't/couldn't 表示否定推测。注意：表推测的否定不能用 mustn't，mustn't 表示“禁止”。

## 5. 非谓语动词

非谓语动词包括不定式（to do）、动名词（doing）和分词（doing/done），不能单独充当谓语。

- 不定式：表示目的与将来，常与 decide、want、hope、plan、refuse、offer 等搭配；
- 动名词：表示习惯与抽象概念，常与 enjoy、finish、avoid、keep、practice、mind 等搭配；介词后必须用动名词，如 be good at doing；
- 现在分词表示主动、进行，过去分词表示被动、完成。

常用固定搭配：be used to doing（习惯于）、look forward to doing、can't help doing、have difficulty (in) doing、spend time doing；使役动词 make、let、have 后接省略 to 的不定式。

## 6. 高频词汇与写作句型

按主题分组的高频词汇（示例）：

- 学习：knowledge、improve、concentrate、memorize、efficient；
- 科技：technology、innovation、artificial intelligence、digital、device；
- 工作：experience、responsibility、cooperate、deadline、promotion；
- 环保：environment、pollution、recycle、sustainable、conserve；
- 健康：healthy、exercise、balanced diet、mental health、relax。

写作常用连接词与句型：First of all（首先）、Moreover（此外）、However（然而）、In conclusion（总之）；常用句型有 It is important to do...、Not only ... but also ...、The reason why ... is that ...、as far as I'm concerned（就我而言）。
