# 操作系统：进程与调度（演示资料）

## 1. 进程的概念

进程是程序的一次执行过程，是操作系统进行资源分配和调度的基本单位。进程与程序不同：程序是静态的指令集合，进程是动态的、有生命周期的实体。

进程通常包含三部分：程序段（代码）、数据段（变量与堆）和进程控制块 PCB。PCB 是进程存在的唯一标志，记录了进程标识符、状态、优先级、程序计数器、寄存器、内存指针等信息。

进程的基本状态有三种：就绪态、运行态、阻塞态。就绪态是指进程已具备运行条件、正在等待 CPU；运行态是指进程正在 CPU 上执行；阻塞态是指进程因等待某事件（如 I/O 完成）而暂停运行。

## 2. 进程调度

进程调度是指按照某种算法从就绪队列中选择一个进程，将 CPU 分配给它。调度的目标是提高 CPU 利用率、缩短周转时间、保证公平性。

常见调度算法：

- 先来先服务（FCFS）：按到达顺序调度，实现简单，但可能产生护航效应（短作业等待长作业）。
- 短作业优先（SJF）：选择预计运行时间最短的作业，平均等待时间最短，但需要预知运行时间，可能饿死长作业。
- 时间片轮转（RR）：每个进程获得固定时间片，时间片用完则回到就绪队列尾部，适合分时系统。
- 优先级调度：按优先级高低调度，低优先级进程可能饥饿，通常配合老化（aging）机制解决。
- 多级反馈队列：设置多个优先级队列，新进程进入最高优先级队列，时间片用尽降级，兼顾响应与吞吐。

## 3. 进程同步与互斥

多个进程访问共享资源时可能产生竞态条件。临界区是访问临界资源的代码段，进入临界区需要遵循：空闲让进、忙则等待、有限等待、让权等待。

信号量是常用的同步机制：P 操作（wait）申请资源，V 操作（signal）释放资源。生产者-消费者问题、读者-写者问题、哲学家进餐问题都是经典的同步问题。

## 4. 死锁

死锁是指多个进程互相等待对方占有的资源而都无法继续推进的状态。死锁产生的四个必要条件：互斥、占有并等待、不可剥夺、循环等待。

死锁的处理策略：预防（破坏四个必要条件之一）、避免（银行家算法）、检测与解除（资源分配图、抢占或终止进程）。
